Determine the time complexity of the following code.

for i in range(n):
    print(i)

We are doing \(n\) operations, so the time complexity is \(n\).

Problem 2#

Consider the function from Friday’s quiz:

def squares(maximum):

    container = []

    for i in range(maximum):
        container.append(i)

    container2 = []

    for j in container:
        container2.append(j**2)

    container3 = 0

    for k in container2:
        container3 += k

    return container3

What is the complexity? Justify your answer. Write a new, simpler function that does the same as squares(). Calculate your function’s complexity and justify your answer.

We are doing \(n\) iterations for each for-loop. There are 3 of them. While we might say it is time complexity \(\mathcal{O}(3n)\), the complexity is really \(\mathcal{O}(n)\) (scaling complexity by a constant does not affect the complexity,

def squares(maximum):
    return sum([i**2 for i in range(maximum)])

We are taking \(n\) iterations through one for-loop giving us a time complexity of \(\mathcal{O}(n)\) still.

def fibonacci(n):
    if n < 1:
        return 'Need a positive number'
    elif n == 1:
        return 1
    elif n == 2:
        return 2
    else:
        return fibonacci(n-1)+fibonacci(n-2)

x = 1
while x < 10:
    print(fibonacci(x))
    x += 1
