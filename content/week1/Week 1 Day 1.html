Python Object Types & Syntax#

Today is the first day of introduction into Python. Today, we will learn basic vocabulary and syntax for the language.

First, every coding course must start with the classic “hello world” output! If you are running within a jupyter notebook you can:

  • click the triangular icon to the left of the cell
  • click "Run" at the top of the notebook
  • (my preferred method) click "Shift" and "Enter" simultaneously
print('Hello World')

Hello World

Python is an object-based programming language. What we will do today is go over some objects and how to use them. To check what type of object you are dealing with, you can always use the type() function. For example, our first type of Python object:

type('Hello World')

str

Strings#

Notice in the above cell, ‘Hello World’ has a single apostrophe on either side of the phrase. This converts the phrase into the first type of object we’ll encouter called a string. The print() function requires the input to be a string. Otherwise, trying to print makes no sense to the function. Trying to run the following cell produces an error message.

print(Hello World)

  File "<ipython-input-4-10cb182148e3>", line 1
    print(Hello World)
                    ^
SyntaxError: invalid syntax

The error tells us many things. Notice a few from this message:

  1. Which file has the error

  2. At what line in the code the error occured at

  3. What type of error occured Without fixing this error, any code after this line will not run. Fixing this error is what we colloquially call debugging.

Strings are incredibly versatile. You can have whatever character you like combined with any other character.

print("{c!?123_ñ")

Numbers#

Just like in mathematics, there are different types of numbers. An integer and complex number in Python is exactly what it is in math. A float is a real-valued estimate for a number (named after floating point number).

When coding, working with these is nearly the same as working with a calculator. Here are some examples.

# addition
print(10 + 3)  

# subtraction
print(10 - 3) 

# multiplication
print(10 * 3)  

# division
print(10 / 3) 

# integer division (floor)
print(10 // 3) 

# modulus 
print(10 % 3)  

# exponentiation
print(10 ** 3)

Operations between two of the same type doesn’t necessarily preserve that object type.

type(10/5) # integer divided by integer gives float

An integer can be converted to a float exactly by using float(). But, converting a float to a integer by using int() forces rounding.

print(float(4))
print(int(4.2))

Booleans#

Booleans are simply binary values. In Python, there are two boolean-types: True and False. Indeed this is True and not true. Python is a case-sensitive programming language.

These are often useful to sanity check. For example, checking whether 10 is greater than 3:

print(10 > 3)

True

We can even rewrite the above statement using an if statement as follows.

if 10 < 3:
    print(True)

We often like to do logical operations between statements. For this, we can use the phrases and or or. Alternatively, we can use & and | respectively.

print((10 > 3) & (10 > 5))
print((10 < 3) | (10 > 5))

True
True

Behind the screen, True and False are stored as 1 and 0. We can see this by checking whether they are equal under the eyes of Python by using ==.

(True == 1) & (False == 0)

True

We can even do operations using them!

True**2 - 2*True + False

-1

None-Type#

The next data type for the day may seem boring. But, just like the empty set in mathematics, there needs to be a Python type with nothing in it: the only none-type object is None. We typically use None to represent “nothing” in the code.

None == 101

Lists#

The last object for the day is the list object. These work the way you probably would like lists to work. We can collect any other objects into a sequence for safe-keeping.

[1,2,3,4] # an example of a list

[1, 2, 3, 4]

[1,
 2,       3,4    ] # an example of the same list in the eyes of Python

[1, 2, 3, 4]

Let’s assign our first variable to some list and see what operations we can do with lists.

contlist = [3.14, 
            'i am in a list', 
            None, 
            True, 
            False, 
            'why did pi get to be first']

By writing contlist = , we are saying “anytime contlist is written, think of the list it represents”. This allows us to do operations quicker. For example, if we wanted to add an element, we can use list_name.append(element_to_add).

contlist.append(44)

With lists, indexing begins at 0. That is, the first item in contlist is the 0-th item. To find that item, we use list_name[index_of_item].

contlist[0]

3.14

To select a sequence of items, we can use list_name[start_index:stop_index].

print(contlist[0:3])
print(contlist[3:]) # leaving stop index empty means end at the end of list
print(contlist[:3]) # leaving start index empty means start at start of list

For Loops#

One canonical method in Python coding is using a “for loop”. When we need to something iteratively, this may be the first starting point. We will discuss these today and tomorrow. Lets learn through practice.

contlist = []        # start with an empty list
for i in range(10):  # for each number from 0 to 9
    contlist.append(i**2) # append the number squared to the list
    
    
contlist

[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

These are incredibly powerful tools. But, can become unruly so be careful! For example, the following may take much, much longer than the previous cell.

contlist = []
for i in range(10000000):
    for j in range(10000):
        contlist.append(i*j**2)

  1. Without using Python, determine the value of:

((7 + 3) * 4 - 5 ** 2) // 3

Now implement it in Python to determine if you obtain the same result.

print(137 % 12)

Why are the answers different?

x = 8

To update the value of x by adding 4, we could write x = x + 4 or more simply x += 4. Likewise, for the other basic operations. If we did the following,

x += 4
x *= 3
x -= 10

what would the final value of x be?

  1. Find the remainder when

7 ** 50

is divided by 3.

a + b = 25
a * b = 144

Find all integer solutions (a, b).
