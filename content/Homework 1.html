Homework 1 (due Friday, July 3rd)#

This assignment is designed to be practice outside of in-class lab.

There are 5 sections. Please pick 5 problems from each section to complete (25 questions total).

Feel free to do more than 25!

Section 1: Basic Arithmetic#

Write code below to compute the following:

  1. $2^4-16+(\frac{288}{7})$
  2. $(10^2+13^4-12^3)^8$
  3. $122^{1/2}-1980^{1/3}$
  4. $3.14^{{3.14}^{3.14}}$
  5. $\frac{3}{7}\cdot\frac{7}{5}\cdot\frac{3.14}{546}$
  6. $456\cdot 32~ (mod~22)$
  7. $100000\div 345~(mod~10)$
  8. $15\cdot 14 \cdot 13 \cdots 3\cdot 2 \cdot 1$
  9. $(12345\cdot 67891011)^{1 / 12345}$
# please put the problem number you are working on in comment mode by using "#" before the problem number

Section 2: Statement Translation#

Translate the following statements in to code below.

  1. If 5 is greater than $x$, print 'yes'.
  2. $y$ greater than 6 or $y$ equal to $x$
  3. $a$ equal to $b$ and $a$ equal to $c$
  4. If $a$ equal to $b$, then print $c$.
  5. For each of the first five integers, add them to a list entitled 'contlist'.
  6. For each element of 'contlist', print the number cubed.
  7. If $x$ is greater than $a$, print $b$. Otherwise, print $x$ squared and set $b$ equal to $x$ squared.

Section 3: Output Prediction#

Without coding, what would the output of the following lines be? Briefly explain why that would be the output.

  1. 5 > 3
  2. ( 10 < 24 ) & ( 10 > 4 )
  3. ( 10 >= 24 ) and ( 10 > 4 )
  4. ( 2 >= 4 ) | ( 2 >= 0 )
  5. x = 4 if x < 3: print('yes') else: print('no')
  6. x = 4 if x < 10: print('yes') elif x < 9: print('no')
  7. for i in [1,3,10]: i **= 2 print(i)
  8. for i in [1,3,10]: i **= 2 print(i)
  9. x = 4 x = 5 x = 6 print(x)

Section 4: Slicing, Indexing, & For-Loops#

  1. Given the string 'homework', use slicing in one line of code to print 'hmwr'
  2. Given the tuple (43, 42, 41, 40, 39), use slicing in one line of code to print (42, 39)
  3. Write a for-loop that prints 'success!' after the loop is done iterating.
  4. Use a for-loop to print of every multiple of 2 between 0 and 50.
  5. Use a for-loop to find the minimum value of some list.
  6. Write a for-loop that uses slicing to take larger and larger slices of a sequence. For example, [1,2,3,4] going through the for-loop would produce [1], [1,2], [1,2,3], then [1,2,3,4].

Section 5: Functions#

For each of the following functions, pick a test input to verify your code works.

  1. Write a function underscore(list) that takes an input list of strings, list, and outputs one string with _ between the previously separated elements. For example, ['this', 'is', 'a', 'list'] would output 'this_is_a_list'.
  2. Write a function factorial(n) that takes input integer n and outputs $n!$ (recall $n! = n\cdot (n-1)\cdot (n-2)\cdots 3\cdot 2\cdot 1$)
  3. Write a function fibonacci(n) that takes input integer n and computes the $n$-th Fibonacci number (recall the next Fibonacci number in the sequence is defined by adding the two previous terms: 0,1,1,2,3,5,8,13,...)
  4. Write a function that converts integers to base 2. For example, the number 17 in base 2 is 10001 since $17 = 1\cdot 2^4+0\cdot 2^3+0\cdot 2^2+0\cdot 2^1+1\cdot 2^0$
  5. Write a function that converts a number into US standard money formatting (every 3 digits contain a comma and demical separates cents from dollar). That is, design a function that takes a number like $123456789.10$ and outputs $ \$123,456,789.10$
  6. Write a function reverse(seq) that takes an input sequence seq and outputs the reversed version of the sequence.
  7. Write a function that adds up the elements in a given list.
  8. Write a function that finds the maximum in a list of integers (without using any built-in maximum finding functions)
