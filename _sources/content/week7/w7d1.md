### Kruskal's Algorithm

What we have discussed is an introduction to the next section of the class: <i>graph algorithms</i>. The first algorithm we will cover is exactly what we have performed on this graph. First, some lingo.

````{prf:definition} Weighted Graphs
A <i>weighted graph</i> is some graph $G=(V,E)$ where each edge $e\in E$ is assigned some positive number we call a <i>weight</i>. On the contrary, an <i>unweighted graph</i> does not have such assignments.
````
<u>Note:</u> Lots of applications can benefit from edges being allowed to be negative or zero. For our purposes, the above definition will actually make things easier.

````{prf:question}
How does Menger's theorem work for weighted graphs?
````

````{prf:definition} Minimum Spanning Tree
A <i>minimum spanning tree</i> of some weighted, connected graph $G$ is a spanning tree such that the sum of all the edge weights is less than or equal to every other spanning tree in $G$.
````

Formalizing the process we have been performing, we introduce the following algorithm:

````{prf:definition} Kruskal's Algorithm

- Input: A connected graph $G=(V,E)$
- Body: Build a minimum spanning tree $T$
    - 1. Initialize a graph $T$ on vertices $V$ with $m=0$ edges
    - 2. While $m<n-1$:
        - 1. Remove edge with minimum weight $e\in E$ 
        - 2. If adding $e$ to $T$ creates a cycle, do not add it. Otherwise, do.
- Output: A minimum spanning tree $T$ of $G$
````
