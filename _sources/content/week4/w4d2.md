### Warmup

````{prf:question}
Recall that in the previous lecture we proved the following:

"Let $G$ be a connected graph. If $\{u,v\}$ is some cut-edge of $G$, then $P=(\{u,v\})$ is the only path from $u$ to $v$."


1. Let $G$ be a connected graph. Prove that if $P=(\{u,v\})$ is the only path from $u$ to $v$, then $\{u,v\}$ is a cut-edge of $G$.

2. What is $\epsilon(G)$ for the graphs of the type described above?

3. Recall "edge-connectivity" is the minimum number of edges we need to remove to disconnect the graph. What might "vertex-connectivity" mean?
````

````{dropdown} Answer
:class: dropdown
1. Again, intuitively, we have only one edge that we'll remove to create a disconnected graph.

<img src="../photos/week4/w4d1.7.png" height=240px align=center>

We'll use this intuition to prove the result. One way to prove the result follows:

"Let $G$ be a connected graph. Assume $P=(\{u,v\})$ is the only path from $u$ to $v$. Consider removing $\{u,v\}$ to obtain $G-\{u,v\}$. Since we have removed the only path from $u$ to $v$, there is no path from $u$ to $v$ in $G-\{u,v\}$. So, $G-\{u,v\}$ is disconnected. Therefore, $\{u,v\}$ is a cut-edge."

This is a classic proof technique. Say we want to prove "A if and only B". What we might do is prove first that "If A, then B". Second, we prove "If B, then A". This means "A if and only B" holds. 

Since we did this, we know the following:

"Let $G$ be a connected graph. $\{u,v\}$ is some cut-edge of $G$ if and only if $P=(\{u,v\})$ is the only path from $u$ to $v$."

2. For a graph like above, what is $\epsilon(G)$? Well, we only need to remove a single edge to disconnect the graph. So, $\epsilon(G)=1$.

3. "Vertex-connectivity" might involve disconnecting a graph by removing vertices. This is what we'll discuss today.
````

### Connectivity

````{prf:definition} Vertex-Connectivity
The *vertex-connectivity* of a graph $G$, $\kappa(G)$, is the minimum number of vertices whose removal (and the edges that contain them) disconnects the graph $G$. Equivalently, if $G=(V,E)$ is a graph, $\kappa(G)$ is the size of the smallest set $W\subseteq V$ such that $G$ without vertices in $W$ and the edges that contain them is disconnected. 
````
For example, the following graph needs only $A$ and its edges to be removed to disconnect the graph:

<img src="../photos/week4/w4d2.1.png" height=240px align=center>

So, the vertex-connectivity of the graph is only 1. But, pretend we had added a vertex with no edges:

<img src="../photos/week4/w4d2.2.png" height=240px align=center>

Since $G_2$ is already disconnected, we don't need to remove any vertices to disconnect it. This intuition leads to the following theorem.

````{prf:theorem}
$\epsilon(G)=0$ if and only if $\kappa(G)=0$
````
````{prf:proof}
Note that if $\epsilon(G)=0$ or $\kappa(G)=0$, the graph $G$ is disconnected (since we don't need to remove anything to disconnect the graph!). 

$\rightarrow$ Assume $\epsilon(G)=0$ Then, $G$ is disconnected and no vertices are needed to disconnect it. Therefore, $\kappa(G)=0$.

$\leftarrow$ Assume $\kappa(G)=0$ Then, $G$ is disconnected and no edges are needed to disconnect it. Therefore, $\epsilon(G)=0$.

Therefore, we have our result.
````

````{prf:question}
If $\epsilon(G)=1$, what is $\kappa(G)$?
````
````{dropdown} Answer
:class: dropdown

Well, if $\epsilon(G)=1$, we only need to remove a single edge to disconnect the graph. The graph would vaguely look something like the following:

<img src="../photos/week4/w4d1.7.png" height=240px align=center>

If a single edge disconnects the graph, we can definitely remove one of the endpoints to disconnect the graph too! That is, we could take $u$ off the graph to disconnect it (likewise, $v$). So, $\kappa(G)=1$.
````

````{prf:question}
What about if $\epsilon(G)=k$? What will $\kappa(G)$ be then?
````

````{dropdown} Answer
:class: dropdown

Well, it might be the case that there is only one pair of vertices for each edge:

<img src="../photos/week4/w4d2.3.png" height=240px align=center>

In this case, we can remove the $k$ vertices on the left and disconnect the graph. But, maybe some edges share vertices:

<img src="../photos/week4/w4d2.4.png" height=240px align=center>

In this case we could remove $k-1$ vertices on the right and disconnect the graph. But, either way, we could remove $k$ vertices and still be fine! This intuition leads to the following theorem.
````

````{prf:theorem}
For a graph $G$, $\kappa(G)\leq \epsilon(G)$.
````
