# Lecture 5: Trails & Walks

````{prf:theorem}
If there is an open $uv$-walk, then there is an open $uv$-path.
````

````{prf:corollary}
If there exists an open $uv$-walk from every pair of vertices in a graph $G$, $G$ is connected.
````
