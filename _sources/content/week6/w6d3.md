# Lecture 14: Menger's Theorem & Proof

We are going to prove Menger's Theorem in this lecture:

````{prf:theorem} Menger's Theorem
Let $u$ and $v$ be distinct vertices in $G$ with <u>no edge</u> between them. Then, the minimum number of vertices in a $uv$-separating set is exactly the maximum number of internally disjoint $uv$-paths (i.e. $\psi_G(u,v)=\kappa_G(u,v)$).
````

### Assumptions

For the rest of lecture we will assume $G=(V,E)$ has two distinct vertices $u$ and $v$ with no edge between them in $G$.

### Subproblems

We will use a couple results in the proof of Menger's Theorem. Let's prove these first.

````{prf:lemma} Problem 1
Menger's theorem holds for graphs with no edges.
````

````{prf:lemma} Problem 2
$\psi_G(u,v)\leq \kappa_G(u,v)$
````

````{prf:lemma} Problem 3
If $P=(\{u,x_1\},\{x_1,x_2\}, \dots, \{x_t,v\})$ is some shortest $uv$-path, then <u>every</u> minimum $uv$-separating set in the graph without the edge $\{x_1,x_2\}$, $G-\{x_1,x_2\}$, contains $\geq \kappa_G(u,v)-1$ vertices.
````

### Proof of Menger's Theorem
We are going to prove this theorem by induction on the number of edges. Recall the assumptions above about $G=(V,E)$. 

````{prf:proof}

<u>__Base Case__</u>: Let $|E|=0$

See problem 1!

<u>__Hypothesis__</u>: Assume Menger's holds for all graphs on $|E|\leq m-1$ edges.

<u>__Induct__</u>: We need to show that this implies Menger's holds for all graphs on $m$ edges now.

By Problem 2, we know $\psi_G(u,v)\leq \kappa_G(u,v)$. 

Note that if $\kappa_G(u,v)=0$, we need to remove zero vertices to ensure no $uv$-paths. Then, there's already no $uv$-paths and so $\psi_G(u,v)=0$. If $\kappa_G(u,v)=1$, then we need to remove one vertex to ensure there's no $uv$-path. It may be the case that multiple paths go through this vertex, but there is definitely only internally disjoint $uv$-path (i.e. a path that goes through this removal vertex cannot be disjoint from another path that goes through this removal vertex). So, $\psi_G(u,v)=1$. Therefore, for values 0 and 1, we have $\kappa_G(u,v)=\psi_G(u,v)$. So, we can consider the cases when $\kappa_G(u,v)\geq 2$. There are three cases we will consider.

1. *There is a minimum $uv$-separating set $W\subseteq V$ containing a vertex $x$ such that $x$ shares and edge with both $u$ and $v$.*

Proof soon to come.

2. *There is a mininum $uv$-separating set $W\subseteq V$ containing a vertex with an edge to $u$ and <u>not</u> $v$ and a vertex with an edge to $v$ and <u>not</u> $u$.*

Proof soon to come.

3. *Every minimum $uv$-separating set $W\subseteq V$ has all vertices sharing an edge with $u$ and not $v$ or $v$ and not $u$.*

Proof soon to come.
````
