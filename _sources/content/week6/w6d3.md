# Lecture 14: Menger's Theorem & Proof

We are going to prove Menger's Theorem in this lecture:

````{prf:theorem} Menger's Theorem
Let $u$ and $v$ be distinct vertices in $G$ with <u>no edge</u> between them. Then, the minimum number of vertices in a $uv$-separating set is exactly the maximum number of internally disjoint $uv$-paths (i.e. $\psi_G(u,v)=\kappa_G(u,v)$).
````

### Assumptions

For the rest of lecture we will assume $G=(V,E)$ has two distinct vertices $u$ and $v$ with no edge between them in $G$.

### Subproblems

We will use a couple results in the proof of Menger's Theorem. Let's prove these first.

````{prf:lemma} Problem 1
Menger's theorem holds for graphs with no edges.
````
````{prf:proof}
No edges means no $uv$-paths. So, no internally disjoint paths ($\psi_G(u,v)=0$). Removing zero vertices ensures no $uv$-paths ($\kappa_G(u,v)=$). So, $\psi_G(u,v)=\kappa_G(u,v)$ for graphs with no edges.
````

````{prf:lemma} Problem 2
$\psi_G(u,v)\leq \kappa_G(u,v)$
````
````{prf:proof}
Assume not. That is, assume $\psi_G(u,v)> \kappa_G(u,v)$. Remove a $uv$-separating set of size $\kappa_G(u,v)$. Since $\psi_G(u,v)> \kappa_G(u,v)$, some internally disjoint path was left untouched. That is, there is still a $uv$-path. This contradicts the assumption that we removed a $uv$-separating set. Thus, $\psi_G(u,v)\leq \kappa_G(u,v)$.
````

````{prf:lemma} Problem 3
If $P=(\{u,x_1\},\{x_1,x_2\}, \dots, \{x_t,v\})$ is some shortest $uv$-path, then <u>every</u> minimum $uv$-separating set in the graph without the edge $\{x_1,x_2\}$, $G-\{x_1,x_2\}$, contains $\geq \kappa_G(u,v)-1$ vertices.
````
````{prf:proof}
Assume not. Then, some $uv$-separating set in $G-\{x_1,x_2\}$ has $\ell<\kappa_G-1$ vertices. 

By removing these $\ell$ vertices from $G$ and either $x_1$ or $x_2$, the paths in $G-\{x_1,x_2\}$ and $P$ is removed from $G$. This is a $uv$-separating set in $G$ of size $\ell+1<\kappa_G$. This contradicts $\kappa_G(u,v)$ being the minimum size for $uv$-separating sets. So, every minimum $uv$-separating set of $G-\{x_1,x_2\}$ must have $\geq \kappa_G(u,v)-1$ vertices.
````

### Proof of Menger's Theorem
We are going to prove this theorem by induction on the number of edges. Recall the assumptions above about $G=(V,E)$. 

````{prf:proof}

<u>__Base Case__</u>: Let $|E|=0$

See problem 1!

<u>__Hypothesis__</u>: Assume Menger's holds for all graphs on $|E|\leq m-1$ edges.

<u>__Induct__</u>: We need to show that this implies Menger's holds for all graphs on $m$ edges now.

By Problem 2, we know $\psi_G(u,v)\leq \kappa_G(u,v)$. 

Note that if $\kappa_G(u,v)=0$, we need to remove zero vertices to ensure no $uv$-paths. Then, there's already no $uv$-paths and so $\psi_G(u,v)=0$. If $\kappa_G(u,v)=1$, then we need to remove one vertex to ensure there's no $uv$-path:

<img src="../photos/week6/idea4.png" height=80px align=center>

It may be the case that multiple paths go through this vertex, but there is definitely only internally disjoint $uv$-path (i.e. a path that goes through this removal vertex cannot be disjoint from another path that goes through this removal vertex):

<img src="../photos/week6/idea5.png" height=120px align=center>

So, in this case, $\psi_G(u,v)=1$. Therefore, for values 0 and 1, we have $\kappa_G(u,v)=\psi_G(u,v)$. So, we can consider the cases when $\kappa_G(u,v)\geq 2$. There are three cases we will consider.


1. *There is a minimum $uv$-separating set $W\subseteq V$ containing a vertex $x$ such that $x$ shares and edge with both $u$ and $v$:

<img src="../photos/week6/idea6.png" height=240px align=center>

Consider $W-x$ in the graph without $x$ and its edges, $G-x$. If $W-x$ were not a minimum $uv$-separating set in $G-x$, $W$ would not be minimum in $G$ (i.e. there would be some smaller set than $W$ that could be used as a $uv$-separating set in $G$). Note that $|E(G-x)|<m$. So, the induction hypothesis applies. Since $|W-x|=\kappa_G(u,v)-1$, there is a maximimum of $\kappa_G(u,v)-1$ internally disjoint $uv$ paths in $G-x$.

To these $\kappa_G(u,v)-1$ internally disjoint $uv$ paths in $G-x$, we add one more internally disjoint $uv$-path when including $x$. So, the maximum number of internally disjoint $uv$-paths in $G$ is $\kappa_G(u,v)$.

2. *There is a mininum $uv$-separating set $W\subseteq V$ containing a vertex with an edge to $u$ and <u>not</u> $v$ and a vertex with an edge to $v$ and <u>not</u> $u$.*

<img src="../photos/week6/idea7.png" height=240px align=center>

Let $W=\{w_1,w_2,\dots, w_{\kappa_G}\}$. Let $G_u$ be the subgraph of only paths between $u$ and $w_i$. Likewise $G_v$ be only paths between $w_i$ and $v$.

<img src="../photos/week6/idea8.png" height=240px align=center>

We are going to take $G_u$ and add a vertex $v'$ to obtain $G_u'$. In $G_u'$, $v'$ will share a single edge with each $w_i\in W$. 

<img src="../photos/week6/idea9.png" height=240px align=center>

By assumption, we have a $w_i\in W$ that does not share an edge with $v$. This means the path from this $w_i$ to $v$ in $G$ has to be longer than a single edge. So, if $|E(G)|=m$, then $|E(G_u)|<m$.

So, the induction hypothesis applies to $G_u'$. So, there are $\kappa_G(u,v)$ internally disjoint $uv$-paths in $G_u'$. A similar argument applies to $G_v$ and adding a vertex $u'$ to share an edge with each $w_i$ in $G_v'$.

<img src="../photos/week6/idea10.png" height=240px align=center>

By taking a $uw_i$-path from $G_u$ and $w_iv$-path in $G_v$, we have an internally disjoint $uv$-path in $G$. Since there are $\kappa_G$ such paths in $G_u'$ and $G_v'$, we have $\kappa_G$ such paths in $G$.

<img src="../photos/week6/idea11.png" height=240px align=center>

3. *Every minimum $uv$-separating set $W\subseteq V$ has all vertices sharing an edge with $u$ and not $v$ or $v$ and not $u$.*

<img src="../photos/week6/idea13.png" height=240px align=center>

Note that it suffices to show either case implies the result. So, let's pretend the first case holds (i.e. all vertices in the set share an edge with $u$ and not $v$). Let $P=(\{u,x_1\},\{x_1,x_2\},\dots,\{x_t,v\})$ be a shortest path in $G$. Consider $G-\{x_1,x_2\}$.

<img src="../photos/week6/idea12.png" height=240px align=center>

From Problem 3, we know every minimum $uv$-separating set in $G-\{x_1,x_2\}$ contains $\geq \kappa_G(u,v)-1$ vertices. 

Suppose every minimum $uv$-separating set in $G-\{u,v\}$ contains exactly $\kappa_G(u,v)-1$ in this case. Let $S=\{s_1,s_2,\dots, s_{\kappa_G-1}\}$ be such a set in $G-\{x_1,x_2\}$. Note that $S$ with $x_1$ will be a minimum $uv$-separating set since removing the vertex $x_1$ will also delete edge $\{x_1,x_2\}$. Since $S$ with $x_1$ is a minimum $uv$-separating set in $G$, by assumption, each of the vertices in $S$ with $x_1$ will share an edge with $u$. But, removing the vertex $x_2$ also deletes the edge $\{x_1,x_2\}$, so $S$ with $x_2$ is also a minimum $uv$-separating set in $G$. So, that must means $x_2$ also shares an edge with $u$ by assumption. This means the path $P'=(\{u,x_2\},\{x_2,x_3\},\dots, \{x_t, v\})$ is one edge shorter than $P$. This contradicts the assumption that $P$ is shortest length. So, there must be $\geq \kappa_G(u,v)$ vertices in a minimum $uv$-separating set in $G-\{x_1,x_2\}$. Note that $G-\{x_1,x_2\}$ is a subgraph of $G$. So, if $\kappa_G(u,v)$ is the minimum size of $uv$-separating set, this set must also be a $uv$-separating set in $G-\{x_1,x_2\}$. So, the minimum size of a $uv$-separating set in $G-\{x_1,x_2\}$ is $\kappa_G(u,v)$. 

Finally, note that $|E(G-\{x_1,x_2\})|<m$. So, the induction hypothesis applies and the maximum number of internally disjoint $uv$-paths in $G-\{x_1,x_2\}$ is $\kappa_G(u,v)$. These paths will also be internally disjoint $uv$-paths in $G$. By Problem 2, $\psi_G(u,v)\leq \kappa_G(u,v)$. So, $\psi_G(u,v)=\kappa_G(u,v)$.


Therefore, Menger's theorem holds for graphs with $m=0,1,2,3,\dots$ edges. 
````
