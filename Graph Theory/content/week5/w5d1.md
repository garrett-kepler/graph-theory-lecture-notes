### Warmup

````{prf:question}
On Friday, we started to prove the following:

"A graph $G$ is connected if and only if it has a spanning tree."

We proved that if $G$ has a spanning tree, then $G$ is connected.

Try proving if $G$ is connected, then it has a spanning tree.
````

````{dropdown} Answer
:class: dropdown

Let $G=(V,E)$ be a connected graph. Then, there exists some connected spanning subgraph $H$ such that $H$ has the minimum number of edges.

Note that $H$ cannot have any cycles since edge removal along the cycle would still leave $H$ connected. This is impossible to do if $H$ has the minimum number of edges possible.

So, $H$ has no cycles and it is a connected, spanning subgraph. Thus, $H$ is a spanning tree. So, the result.
````

````{prf:theorem}
A graph $G$ is connected if and only if $G$ has a spanning tree.
````

### Trees

````{prf:theorem} 
If $T$ is a tree on $n$ vertices, then it has $n-1$ edges.
````

````{prf:proof}
Let $T_n=(V,E)$ be a tree such that $|V|=n$.

<u>Base Case</u>: Let $n=2$. Then, we have a graph on 2 vertices with a single edge. That is, the tree has $n=2$ vertices and $n-1=1$ edges. So, the statement holds for $n=2$.

<u>Inductive Hypothesis</u>: Assume the statement holds for $n\leq k$. That is, for all trees on $n\leq k$ vertices, then there are $n-1$ edges.

<u>Induct</u>: Let $T_{k+1}$ be a tree. Consider removing some edge $\{u,v\}$ that results in 2 components $T_r$ and $T_{k+1-r}$ ($2\leq r\leq k-2$ so that we have edges in either component). Note that $T_r$ and $T_{k+1-r}$ are still connected and have no cycles so they are also trees.

Since $r\leq k$ and $k+1-r\leq k$, the inductive hypothesis applies to $T_r$ and $T_{k+1-r}$. That is, we know $T_r$ has $r-1$ edges and $T_{k+1-r}$ has $k+1-r-1$ edges.

So, we know that $T_{k+1}$ has $r-1$ edges from $T_r$ and $k+1-r-1$ edges from $T_{k+1-r}$. Including the removed edge $\{u,v\}$, we know $T_{k+1}$ has $1+(r-1)+(k+1-r-1)=k$ edges total. Thus, $T_{k+1}$ has $k$ edges. 

Therefore, $T_n$ has $n-1$ edges for all $n\geq 2$.  
````

````{prf:theorem}
Let $T$ be a tree. Then, there is exactly one path between every pair of distinct vertices.
````
````{prf:proof}
Let $T=(V,E)$ be a tree. Assume $T$ has more than one $uv$-path for some distinct vertices $u,v\in V$. Consider two of these paths, $P_1$ and $P_2$.

At some point in $P_1$ and $P_2$, there are a pair of vertices $x_i$ and $x_j$ that exist in <u>both</u> $P_1$ and $P_2$. Then, there is an $x_ix_j$-path in $P_1$ and an $x_ix_j$-path in $P_2$. By taking the edges of each of the $x_ix_j$-paths, we have a cycle (an $x_ix_i$-path).

Therefore, $T$ has exactly one path from $u$ to $v$.
````
