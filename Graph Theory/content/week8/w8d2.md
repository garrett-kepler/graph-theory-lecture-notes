# Lecture 16: Breadth-First Search

First, recall BFS from last class:


````{prf:definition} Breadth-First Search (graph)
- Input: A graph $G=(V,E)$ and a starting vertex "$root$"
- Body: Build a tree $T$
     1. Initialize a graph $T$ on vertices $V$ with no edges
     2. Label $root$ explored
     3. Let $Q=(root)$ (an ordered list).
     4. While $Q$ is not empty:
        - 4a. Remove first element $u\in Q$.
        - 4b. For each edge $\{u,v\}\in E$:
            - If $v$ is not unexplored,
                - label it explored
                - add $\{u,v\}$ to $T$ 
                - add $v$ to end of $Q$
- Output: A tree $T$ from $G$
````




### Generating Spanning Tree

````{prf:theorem}

If a connected graph is inputted into B.F.S. (graph) from last class, the output will be a spanning tree.

````

````{prf:proof}
Let $G=(V,E)$ be inputted into BFS (graph) with $T$ being its output. We want to show that:

1. $T$ is spanning (has all the vertices of $G$)
2. $T$ is connected (has a path between every pair of distinct vertices)
3. $T$ has no cycles (has no paths that start and end at the same vertex)

__Spanning__: Well, in our algorithm above, step 1 initializes $T$ with all the vertices of $G$. So, $T$ is spanning!

__Connected__: We did a proof by induction in class. Consider also a proof by contradiction. Assume $T$ is not connected. Then, there is some vertex $u$ and $v$ with no path between them. We can assume without loss of generality that $u$ was labelled explored first. 

This means that $u$ was labelled explored, all the edges with $u$ and any unxplored vertices were added to $T$, and yet we ended up with no path between $u$ and $v$.
