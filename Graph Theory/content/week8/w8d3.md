### The DFS Algorithm

````{prf:definition} Depth-First Search (graph)
- Input: A graph $G=(V,E)$ and a starting vertex "$root$"
- Body: Build a tree $T$
     1. Initialize a graph $T$ with no edges and only the vertex $root$ 
     2. Do visit$(root)$ (i.e. apply procedure below)
     > <u>visit($v$):</u>
     > - Input: $v$ (a vertex in $G$)
     > - Body: For each $\{v,w\}\in E$:
     >      - If $w$ not in $T$,
     >          - add $w$ and $\{v,w\}$ to $T$
     >          - visit($w$)
- Output: A tree $T$ from $G$
````

DFS works by repeating the function visit() <it>everytime a new vertex is added to $T$</it>. When we add this new vertex, we run visit() until its done then <it>go back</it> to finish a previous visit() we had not completed.

### Generating a Spanning Tree
````{prf:theorem}
Inputting a connected graph into DFS produces a spanning tree.
````
````{prf:proof}
Let $G=(V,E)$ be a connected graph inputted into DFS (graph) algorithm above with $T$ being its output. We want to show that:

1. $T$ is spanning (has all the vertices of $G$)
2. $T$ is connected (has a path between every pair of distinct vertices)
3. $T$ has no cycles (has no paths that start and end at the same vertex)

__Spanning__: Assume not. That is, let some set $U\subseteq V$ be vertices that are not added to $T$ but are in $G$. Since $G$ is connected, there is at least one edge in $G$ between some vertex in $U$ and some vertex <u>not in</u> $U$ (otherwise there would be no path between vertices in $U$ to the rest of the graph). Let $x\in U$ and $y\notin U$ be such that $\{x,y\}\in E$. 

Since $y\notin U$, $y$ must have been added to $T$ via visit($y$). By applying visit() to $y$, the edge $\{x,y\}$ was considered, visit() noticed the vertex $x$ was <u>not</u> in $T$, and so $x$ would be added to $T$. This contradicts $x$ being in the set of unadded vertices $U$. So, $U$ must be empty such that $T$ is spanning for $G$.

__Connected__: Try it yourself! (Similar to BFS proof) 

__No Cycles__: Note that DFS adds vertices to $T$ one by one. Also not that when adding edges to $T$, we only add an edge between a new vertex and a vertex already in $T$. So, the only way to create a cycle is for the new vertex to be added such that it shares an edge between two vertices already in $T$. 

If the new vertex $x$ shared an edge in $G$ with two vertices $y$ and $z$ who are already in $T$, either $y$ or $z$ must have been visited first and $x$ added to $T$ (by visit($y$) or visit($z$)). By the time the other vertex was visited, $x$ is already in $T$ and no edge would be added. So, $x$ cannot share an edge with both $y$ and $z$. So, $T$ has no cycles. 

Therefore, $T$ is spanning, connected (left to you to prove), and has no cycles. Thus, $T$ is a spanning tree of $G$.
````
