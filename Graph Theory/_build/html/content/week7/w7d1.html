They show you the map with the miles each road consists of:



This graph now has extra information. Each edge now has a mileage.

The problem is now this:

  1. Find a spanning tree.

  2. Ensure this specific spanning tree has the lowest total amount of miles possible.

  1. What might you call this graph object you are looking for?

  2. Write a step-by-step process and execute it.

We will repeat the process from above to find a spanning tree. We will consider adding an edge to see if it creates a cycle. If so, we won’t add it to \(T\). But, we will consider edges with the least miles first.

That is, we will take the edge with the smallest mileage off \(G\), determine whether this will create a cycle in \(T\), and add the edge to \(T\) if no cycle is created.

Kruskal’s Algorithm#

What we have discussed is an introduction to the next section of the class: graph algorithms. The first algorithm we will cover is exactly what we have performed on this graph. First, some lingo.

Definition 39 (Weighted Graphs)

A weighted graph is some graph \(G=(V,E)\) where each edge \(e\in E\) is assigned some positive number we call a weight. On the contrary, an unweighted graph does not have such assignments.

Note: Lots of applications can benefit from edges being allowed to be negative or zero. For our purposes, the above definition will actually make things easier.

Question 27

How does Menger’s theorem work for weighted graphs?

Definition 40 (Minimum Spanning Tree)

A minimum spanning tree of some weighted, connected graph \(G\) is a spanning tree such that the sum of all the edge weights is less than or equal to every other spanning tree in \(G\).

Formalizing the process we have been performing, we introduce the following algorithm:

Definition 41 (Kruskal’s Algorithm)

  • Input: A weighted, connected graph \(G=(V,E)\)

  • Body: Build a minimum spanning tree \(T\)

      1. Initialize a graph \(T\) on vertices \(V\) with \(m=0\) edges

      1. While \(m<n-1\):

        1. Remove edge with minimum weight \(e\in E\)

        1. If adding \(e\) to \(T\) creates a cycle, do not add it. Otherwise, do.

  • Output: A minimum spanning tree \(T\) of \(G\)
