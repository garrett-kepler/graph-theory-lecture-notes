Variables, Statements, & For-Loops#

Now that we have grasp of some basic objects in Python, let’s discuss what we can do with them.

Variables#

Last class, we implicitly introduced the concept of a “variable” in Python. To assign a variable x, we simply use x = whatever_we_want. For example,

x = 5
y = ['this is a string: '+str(3.14), 'this is a number: '+str(int('4'))]

print(x)
print(y)

5
['this is a string: 3.14', 'this is a number: 4']

After assignment, Python will understand any operation on the variable as an operation on the actual object itself. That is, once we have a variable, we can perform operations on the representation of the object. For example, since we ran the above and set x = 5, we have

x**2 + x - 2

28

x**2 + x - 2 == 5**2 + 5 - 2

True

We can also reassign at will. But, the last running assignment will be whatever Python refers to. For example,

x = 5   # initially x is assigned 5
x = 4   # by reassigning x to be 4, x is 4 for every line of code after this
print(x)

4

Conditional Statements#

One thing we will cover today is how to use conditional statements in Python. By statement, we mean a line of code that does not transform any object (for instance x = x + 2), but determines the truth value of a phrase (for instance x > 2). For example, we can compute the truth value (boolean value) of the following statement:

x > 3 # remember that right now x = 4

True

A conditional statement utilizes if, else, and elif to determine whether or not to perform an operation. A straightforward example:

x = 4
if x > 3:    # if variable x is greater than 3
    x **= 2  # then reassign x as x squared (x = x**2)
x

16

What Python reads this as is “if A is true, then perform B”. If we want to have an alternative operation in the case that A is not true, we can utilize the else statement. Try running the following:

x = float(input('what would you like x to be? ')) # a simple input to demonstrate if else statement

if x > 3:    # if variable x is greater than 3
    x **= 2  # then reassign x as x squared (x = x**2)

else:           # if variable x is less than or equal to 3
    x += 2  # then reassign x as x + 2 (x = x + 2) 
    
print(x)

All if statements are independent. That is, multiple statements can be true at the same time. So, multiple operation can occur at once:

x = 10

if x < 100:
    x += 1   # x is now 11
if x < 1000: # since x is 11, this still applies
    x += 1
    
print(x)

12

The elif statement allows you to make more conditions than a simple if else block. elif meaning “else if” follows an if statement.

x = 10

if x < 100:    # this applies to x
    x += 1     # x is now 11
elif x < 1000: # since x already went through the above if statement,
    x += 1     #  this doesn't apply
    
print(x)

11

These can be useful if you want to do piecewise functions or anything involving multiple conditions. For example, the function

\[\begin{split}\begin{align*} f(x)&=\begin{cases} x+2~~\text{if } 2\geq x\geq 1\\ x-2~~\text{if } 3\geq x\geq 2\\ x^2~~\text{if } x\geq 3\\ 2x~~\text{otherwise} \end{cases} \end{align*}\end{split}\]

could be executed using the following cell.

x = float(input('what would you like x to be? ')) 

if 2 >= x >= 1:
    x += 2
    
elif 3 >= x >= 2:
    x -= 2  
    
elif x >= 3:    
    x **= 2  
    
else:          
    x *= 2  
    
print(x)

For-loops#

For-loops are essential to Python programming. “For-loop” because they begin with for and loop through some operation. They allow us to iterate through an object and perform an operation for each element of the object. For example, we can operate on the object itself:

contlist = [1,2,3]
contlist2 = []
contlist3 = []
for i in contlist: # for each element in contlist
    contlist2.append(i+1) # add one to that element and append it to contlist2
    contlist3.append(i**2)
print([contlist, contlist2, contlist3])

[[1, 2, 3], [2, 3, 4], [1, 4, 9]]

Or, even operate on an entirely different object:

x = 1
for i in [1,2,3,4,5,6,7,8,9]:
    if i>3:
        x = x*.5
        print(x)

0.5
0.25
0.125
0.0625
0.03125
0.015625

For-loops are generically formatted as the above two examples. We have some object we iterate over (called an iterable) and assign a variable that will iterate through this iterable object.

A for-loop format is:


    for whatever_variable_you_want in whatever_iterable_you_want:
        some_lines_of_code_that_execute_something

Importantly, like we have discussed at the beginning, the last assignment of a variable is what Python remembers. That is, whatever variable you decide to use in this loop will be assigned the last value it has obtained.

for i in range(15):
    if i < 100000:
        'just look at the output, it will be the last number i is defined to be'
print(i)

Nested For-Loops#

One important feature of for-loops follows the same logic as conditional statements: we can do more than one. For-loops can be compounded (what we call nested). We can have a for-loop inside of a for-loop inside of a for-loop and so on.

count = 0
for i in range(5):
    for j in range(5):
        count += 1
        print('i am step '+str(count))

This can be incredibly useful. Take for example a problem from last lab:

Find all integer solutions \((a,b)\) satisfying

\[\begin{split}\begin{align*} a+b=25\\ a\cdot b= 144 \end{align*}\end{split}\]

We can solve this with a for-loop:

for a in range(25):
    b = 25 - a
    if a*b == 144:
        print([a,b])

[9, 16]
[16, 9]

We can also solve this with a nested for-loop:

for a in range(25):
    for b in range(25):
        if (a*b == 144) & (a+b==25):
            print([a,b])

[9, 16]
[16, 9]

We can even solve this with four for-loops and three conditional statements:

for a in range(25):
    for b in range(25):
        if a+b == 25:
            for c in range(25):
                for d in range(25):
                    if c*d == 144:
                        if [a,b] == [c,d]:
                            print([a,b])

[9, 16]
[16, 9]

I hope you can see the difference between these solutions. Mainly, I hope you can see that the last method is absolutely more complicated than the first two. This is the key: coding is a tool that we should use to our advantage. Correct convoluted code will always work. If that is the only method we have that works, stick with it! If there is a simple way, maybe that’s better. At the end of the day, solving problems is the goal. But, communicating reproducable code is absolutely second on the list.

The last note on this difference: time.

  • ‘A’ if grade ≥ 90

  • ‘C’ if grade ≥ 70

A “leap year” is a calendar year where an extra day is added. The rules are as follows:

  • If divisible by 400, then leap year

  • If divisible by 100, then not a leap year

  • If divisible by 4, then leap year

  • Otherwise, not a leap year

Write a block of code that takes in the variable year and determines if it is a leap year or not.

Write a for-loop that keeps a list of the sum of the first n integers as n ranges from 1 to 30.
