math, numpy, & sympy Libraries#

Three of the most commonly used libraries in Python are math, NumPy, and SymPy. We went over numpy yesterday. Let’s go over math and sympy today.

Although they all perform mathematical operations, each library is designed for a different purpose.

Library

Typical Use

Good For

math

Standard mathematical functions

Individual numbers (scalars)

NumPy

Numerical computing

Arrays, vectors, and matrices

SymPy

Symbolic mathematics

Algebra, calculus, and exact arithmetic

print(math.factorial(5))     # factorial

The SymPy Library#

SymPy performs what we call symbolic mathematics rather than solving numerically like in numpy. To do this, we reform arithmetic in terms of a “sympy symbol”. This object takes much longer to process and deal with than floats, so be careful!

import sympy as sp

---------------------------------------------------------------------------
ModuleNotFoundError                       Traceback (most recent call last)
Cell In[6], line 1
----> 1 import sympy as sp

ModuleNotFoundError: No module named 'sympy'

To create a variable in sympy, we must tell Python to create a sympy symbol object:

x = sp.symbols('x')

Now, anytime the variable x is mentioned, Python knows to refer to the sympy-based arithmetic of the object. One basic operation in sympy is simplification:

print(sp.simplify((x**2 - 1)/(x - 1)))

x + 1

Also, expansion:

print(sp.expand((x + 2)**5))

x**5 + 10*x**4 + 40*x**3 + 80*x**2 + 80*x + 32

We can also factor polynomials:

print(sp.factor(x**2 - 9))

(x - 3)*(x + 3)

And solve quadratics:

solution = sp.solve(x**2 - 4, x) # sp.solve( function, variable )
print(solution)

[-2, 2]

Or evaluate limits:

print(sp.limit(sp.sin(x)/x, x, 0)) # sp.limit( function, variable, limit )

1

Even differentiate:

f = x**3 + 2*x**2 - x
print(sp.diff(f, x))

3*x**2 + 4*x - 1

And integrate:

print(sp.integrate(x**2, x)) # indefinite integral format

print(sp.integrate(x**2, (x, 0, 4))) # definite integral (from 0 to 4)

x**3/3
64/3

The solutions are given by the quadratic formula:

  • Write a function quadratic() that calculates the two roots given by the quadratic formula only if they are real.
