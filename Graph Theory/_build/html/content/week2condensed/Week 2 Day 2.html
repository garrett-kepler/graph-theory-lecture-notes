Working with Libraries#

Today we’ll be talking about libraries and how to use them.

First of all, what is a library? A library is simply a collection of functions that others have written, tested, and (likely) optimized for everyone to use. While some coding languages require you to pay for these libraries, Python is open-source meaning anyone can contribute and no one pays.

Two important libraries we will need today should be built in: numpy and math. To have access to a library, we need to install the library to our system. For example, with numpy,

!pip install numpy

To use a library, we need to import the library into the notebook we are currently using,

import math
import numpy

Important: If you ever find that you do not have a library downloaded, you can try installing it by running this in your notebook: !pip install library_name. Just like the functions we design, all the functions in these libraries are typically dependent on other libraries or base code called dependencies. When using !pip install, your system will typically download and/or update these as well to match whatever version of the library you are downloading.

To use libraries, we typically have to write library_we_want.function_we_want(). Since we might end up writing the same library name hundreds of times, we can assign a variable to the name of the library when we import if we want to:

import numpy as np

Every library comes with an instruction manual called documentation that allows you to find what is required to run a specific library’s function. For example, here is numpy’s and math’s: https://numpy.org/doc/ and https://docs.python.org/3/library/math.html . You should always try referring to the documentation for troubleshooting.

Numpy#

Numpy is one of the most crucial libraries when doing mathematical computing. The reason numpy is so useful is its computational efficiency in most regards.

Numpy introduces a different type of object to the list of Python objects we know now: the numpy array. Similar to a list, a numpy array is a collection of objects. However, unlike a list, applying a function to a numpy array applies the function immediately to the elements.

contlist = [1, 1, 4, 5, 2, 6] # a list
contarray = np.array(contlist) # the numpy array version
type(contlist), type(contarray)

(list, numpy.ndarray)

contlist[0]

1

The only restriction on numpy array elements are that they are all the same type of object. If not, then numpy will often make them the same type.

np.array([1, '1'])

array(['1', '1'], dtype='<U21')

So, how do we work with numpy arrays? The way we would work with numbers (not lists).

4 * contlist + [1]

[1, 1, 4, 5, 2, 6, 1, 1, 4, 5, 2, 6, 1, 1, 4, 5, 2, 6, 1, 1, 4, 5, 2, 6, 1]

contarray

array([1, 1, 4, 5, 2, 6])

4 * contarray + 1

array([ 5,  5, 17, 21,  9, 25])

We also get a speed up when inputting functions:

n = 100000
x = np.linspace(0, 2*np.pi, n)

x

array([0.00000000e+00, 6.28324814e-05, 1.25664963e-04, ...,
       6.28305964e+00, 6.28312247e+00, 6.28318531e+00], shape=(100000,))

# using list indexing
%timeit y = [math.sin(x[i]) + math.exp(x[i]**2) for i in range(n)]

# using numpy ufuncs
%timeit y = np.sin(x) + np.exp(x**2)

75.1 ms ± 1.78 ms per loop (mean ± std. dev. of 7 runs, 10 loops each)

1.88 ms ± 70.6 μs per loop (mean ± std. dev. of 7 runs, 1,000 loops each)

The reason for this speed up is called vectorization . Numpy functions that act on arrays (called universal functions or ufuncs) are designed to execute a single instruction on an entire data set using hardware instructions giving a dramatic speed up in most scenarios.

We can design functions so that they benefit from this same speed up as well. That is, we can vectorize a function:

def f(n):
    return math.sin(n) + math.exp(n**2)

x

array([0.00000000e+00, 6.28324814e-05, 1.25664963e-04, ...,
       6.28305964e+00, 6.28312247e+00, 6.28318531e+00], shape=(100000,))

# method 1


vectf = map(f, x) # for each element in a vector x, apply f

# method 2


g = np.vectorize(f)

%timeit out = list(map(f,x))

%timeit out = g(x)

%timeit out = np.sin(x) + np.exp(x**2)

58.3 ms ± 1.52 ms per loop (mean ± std. dev. of 7 runs, 10 loops each)

56.3 ms ± 511 μs per loop (mean ± std. dev. of 7 runs, 10 loops each)

1.82 ms ± 5.01 μs per loop (mean ± std. dev. of 7 runs, 1,000 loops each)

Not only will numpy arrays speed up our computation for basic problems, but numpy arrays will be our matrix objects in the linear algebra section of this class:

contlist = np.array([1,2,3,4])
matrix = contlist.reshape(2,2)

matrix * matrix # element-wise multiplication

array([[ 1,  4],
       [ 9, 16]])

matrix @ matrix # regular matrix multiplication

array([[ 7, 10],
       [15, 22]])

Given

a = np.array([2, 4, 6, 8])

compute each of the following:

  • a + 3

  • 2 * a

  • a**2

  • a - 1

Do not use a for loop.

The derivative of a function (f(x)) at a point (x) is defined as the limit

\(f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)

provided the limit exists.

Define a function \(g(h)\) that computes the quotient above for a given function \(f\) near a point \(x\). Then, vectorize \(g\).

Using np.linspace(), let \(f(x)=sin(x)\) and compute \(g\) at \(10^{-1}, 10^{-2}, 10^{-3}, 10^{-4}\). This will be an estimate for the derivative of \(f\). Compare to the actual derivative.

Let

\[\begin{split}A=\begin{bmatrix} 2 & 1 \\ 3 & 4 \end{bmatrix}~~~~ B= \begin{bmatrix} 5 & 2 \\ 1 & 6 \end{bmatrix}\end{split}\]

Compute the product.
