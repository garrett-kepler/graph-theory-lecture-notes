Week 1 Day 2 Lab#

Problem 1#

Without using Python, determine the value of:

3 + 5 * 2 ** 3 - 12 // 5

Now implement it in Python to determine if you obtain the same result.

3 + 5 * 2 ** 3 - 12 // 5

41

Problem 2#

Without using Python, determine the value of:

((7 + 3) * 4 - 5 ** 2) // 3

Now implement it in Python to determine if you obtain the same result.

((7 + 3) * 4 - 5 ** 2) // 3

5

Problem 3#

What does the following print?

print(137 % 12)

Explain what the remainder represents.

print(137 % 12)

5

Problem 4#

Determine the values of:

17 / 4
17 // 4
17 % 4

How are these quantities related?

print(17 / 4)
print(17 // 4)
print(17 % 4)

4.25
4

Problem 5#

Evaluate:

2 ** 3 ** 2

Then compare with:

(2 ** 3) ** 2

Why are the answers different?

print(2 ** 3 ** 2)
print((2 ** 3) ** 2)

512
64

The first one is \(2^9\) since we have not specified which power applies first. The second forces \(8^2\).

Problem 6#

Suppose:

x = 8

To update the value of x by adding 4, we could write x = x + 4 or more simply x += 4. Likewise, for the other basic operations. If we did the following,

x += 4
x *= 3
x -= 10

what would the final value of x be?

26

Problem 7#

Find the remainder when

7 ** 50

is divided by 3.

(7 ** 50) % 3

1

Problem 8#

Suppose

a + b = 25
a * b = 144

Find all integer solutions (a, b).

for a in range(13,25):
    b = 25 - a
    if a*b == 144:
        print([a,b])

[16, 9]
