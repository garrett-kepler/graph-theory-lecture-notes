Lecture 4: Paths#

It is Labor Day weekend. A lot of us will be traveling to the west side of Washington. Consider a network of highways across the state:

We can represent this structure as a graph:

Now, cities are vertices. Two vertices share an edge if the cities have a highway between them. Paths in the graph correspond to journeys from city to city.

Pretend we want to go from Pullman to Tacoma.

  1. We will start at vertex F and end at vertex B.

  2. \(P = (\{F,D\}, \{D,C\}, \{C,B\})\) contains vertices \(V_P=(F,D,C,B)\) such that \(F,D,C,\) and \(B\) are distinct and appear as an edge endpoint at most twice.

  3. P is a path!

Warmup#

Question 4

  1. Is this graph connected?

  2. What is the longest path in this graph?

  3. What is the longest a path can be in a connected graph on \(n\) vertices?

Answer

  1. Yes, there is a path from every vertex to every other vertex.

  2. We can start at \(A\) and go lexicographically around the graph all the way to \(G\) and return to \(A\).

  3. On \(n\) vertices, ideally we would visit every vertex like we did in the second part. This is the “longest” a path can be. Let’s define what we mean by “length” now.

Definition 16 (Length of a Path)

The length of a path \(P\) is the number of edges in the path.

One really fun theorem:

Theorem 3

If \(G_1\cong G_2\) and \(G_1\) is connected, then \(G_2\) is connected.

Before proving the above, the following lemma will prove useful:

Lemma 2

Let graphs \(G_1\cong G_2\) have some isomorphism \(\psi\) between them. If \(P\) is a path between \(u\) and \(v\) in \(G_1\), then there is a path \(P'\) in \(G_2\) between \(\psi(u)\) and \(\psi(v)\).

Proof. Let \(G_1=(V_1,E_1)\) and \(G_2=(V_2,E_2)\) be graphs such that \(\psi:V_1\to V_2\) is an isomorphism between them. Let \(P=(\{u_1,u_2\}, \{u_2,u_3\}, \dots ,\{u_{m-1},u_m\})\) be some path in \(G_1\) on vertices \(V_P=(u_1,u_2,\dots,u_m)\).

Consider \(P'=(\{\psi(u_1),\psi(u_2)\}, \{\psi(u_2),\psi(u_3)\}, \dots ,\{\psi(u_{m-1}),\psi(u_m)\})\). Since \(G_1\cong G_2\), the edges \(\{\psi(u_i), \psi(u_{i+1})\}\in P'\) must exist in \(G_2\). Since \(\psi\) is a bijeection and \(V_P=(u_1, u_2, \dots, u_m)\) contains distinct vertices, \(V_{P'}=(\psi(u_1), \psi(u_2), \dots, \psi(u_m))\) contains distinct vertices. Again, since \(\psi\) is a bijection, each edge \(\{u_i,u_{i+1}\}\in E_1\) is mapped uniquely to an edge \(\{\psi(u_i),\psi(u_{i+1})\}\in E_2\) such that no vertex appears more than twice in \(P'\). Thus, each vertex in \(V_{P'}\) is distinct such that it appears at most twice as an endpoint in \(P'\) and no edge in \(P'\) is repeated. Therefore, \(P'\) is a path.

Theorem 4

If \(G_1\cong G_2\) and \(G_1\) is connected, then \(G_2\) is connected.

Proof. Using Lemma Lemma 2, we know any path in \(G_1\) can be mapped to a path in \(G_2\). So, if there is a path between every pair of vertices \(u\) and \(v\) in \(G_1\), there must be a path between every pair of vertices \(\psi(u)\) and \(\psi(v)\) in \(G_2\) (where \(\psi\) is some isomorphism between \(G_1\) and \(G_2\)).

Paths, Trails, & Walks#

Definition 17 (\(uv\)-Things)

  • A \(uv\)-path is a path between vertices \(u\) and \(v\).

  • A \(uv\)-trail is a \(uv\)-path but we can repeat vertices.

  • A \(uv\)-walk is a \(uv\)-path but we can repeat vertices and edges.

For example, consider the following graph.

An example of an \(AB\)-path would be \((\{A,C\},\{C,B\})\). Meanwhile, an \(AB\)-trail that isn’t a path would be \((\{A,C\},\{C,D\}, \{D,E\},\{E,C\}, \{C,B\})\). Lastly, an \(AB\)-walk that is neither a trail nor a path would be \((\{A,C\},\{C,D\}, \{D,C\}, \{C,B\})\). We will discuss these often, so please get some intuition for them!
