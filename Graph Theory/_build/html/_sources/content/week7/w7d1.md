# Lecture 15: Algorithmic Thinking


### Warmup

````{prf:question}
The bus system in Pullman wants to downsize on routes. They are allowed to use any of the following roads.

<img src="../photos/week7/pullman1.png" height=240px align = center>

They <u>really</u> want a <u>unique</u> path between every pair of destinations.

1. What is the graph object they want to find?
2. Write a step-by-step process to find it.
````

For the first question, we're looking for a spanning tree!

For the second question, you might try and do the following:
<ol> 
<li> Start by forming a graph $T$ on these vertices with no edges. 
<li> For each edge <i>e</i> in <i>G</i>:
<ol type="a"><li>Remove the edge from <i>G</i>.
<li> If adding the edge <i>e</i> to <i>T</i> creates a cycle in <i>T</i>, ignore this edge.
<li> Otherwise, add the edge!
</ol></ol>

Let's actually do this. Take the graph $G$. Form $T$ to have the same vertices and no edges.

<img src="../photos/week7/span2.png" height=450px align = center>


Consider some edge in $G$, say the Colfax Sunnyside Park edge:

<img src="../photos/week7/span1.png" height=450px align = center>

This definitely does not form a cycle in $T$, so we'll add it:

<img src="../photos/week7/span3.png" height=450px align = center>

Continuing on, adding Colfax Rosauers does not create a cycle so we'll add that:

<img src="../photos/week7/span4.png" height=450px align = center>


Same with Rosauers to Walmart:

<img src="../photos/week7/span5.png" height=450px align = center>

We'll consider Walmart Sunnyside Park road, but we end up with a cycle so we don't add it!

<img src="../photos/week7/span6.png" height=450px align = center>

So, we move on and repeat this process until we have removed every edge from $G$.
