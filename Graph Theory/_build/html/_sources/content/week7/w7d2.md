### Proof of "Correctness"

We will proceed to prove the <u>correctness</u> of Kruskal's Algo. By proving correctness, we show that indeed Kruskal's Algo generates the output that it claims to generate: a minimum spanning tree.

First, recall Kruskal's Algo:

````{prf:definition} Kruskal's Algorithm

- Input: A weighted, connected graph $G=(V,E)$
- Body: Build a minimum spanning tree $T$
    - 1. Initialize a graph $T$ on vertices $V$ with $m=0$ edges
    - 2. While $m<n-1$:
        - 1. Remove edge with minimum weight $e\in E$ 
        - 2. If adding $e$ to $T$ creates a cycle, do not add it. Otherwise, do.
- Output: A minimum spanning tree $T$ of $G$
````

````{Theorem} Correctness of Kruskal's Algo
Kruskal's algorithm produces a minimum spanning tree from a weighted, connected graph.
````
````{prf:proof}
Let $G=(V,E)$ be a weighted, connected graph. Let $T$ be the output from Kruskal's Algo. We will first show $T$ is a spanning tree.

__Spanning Tree__: Since we initialize $T$ with all of the vertices of $G$, $T$ is already a spanning subgraph of $G$. By not adding edges that create cycles, $T$ has no cycles. The only thing left to prove is that $T$ is connected.

So, assume $T$ is not connected. Then, there are at least two vertices $u$ and $v$ in $T$ with no $uv$-path between them. That is, $u$ and $v$ are in different components of $T$. Call the component $u$ is in $T_1$ and the component $v$ is in $T_2$. 

<img src="../photos/week7/idea1.png" height=240px align=center>

Note that $T_1$ and $T_2$ must also be cycle-less. Since $G$ is connected, there must have been edges between $T_1$ and $T_2$ that Kruskal's Algo considered. The only way to create a cycle by adding one of these edges is if there were already a path between the endpoints of that edge. Since this is not the case for a vertex in $T_1$ and a vertex in $T_2$, Kruskal's Algo would have added an edge between them since at some point this edge is minimum and no cycle is created.
````
