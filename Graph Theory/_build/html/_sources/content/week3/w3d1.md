### Warmup

````{prf:question}
1. What is the maximum number of edges a graph on $n$ vertices can have? What about a simple graph?

2. What is the minimum number of edges a graph on $n$ vertices can have? What about a connected graph?
````

````{dropdown} Answer
:class: dropdown

1. Well, if we do not restrict to being simple... there could be infinitely many edges! But, if the graph is simple, the maximum is $\binom{n}{2}$. 

Think about the definition of simple: no self-loops and no multiple-edges. If we add one edge between each pair of distinct vertices, end up with $\binom{n}{2}$ vertices. "No multiple-edges" means we cannot add another edge between these vertices. "No self-loops" means we cannot add an edge between a vertex and itself. So, we have no more edges we can add. This graph has a special name: *the complete graph*.

2. If we don't restrict to being connected... there could be no edges! That is, we have just a set of vertices with no edges between them. This is still a graph and it has a special name as well: *the empty graph*. But, the empty graph is not a connected one. 

We will prove this later, but the minimum edges we need for a graph to be connected is actually $n-1$. A great example of this is the graph obtained by adding edges to successive vertices. That is, if $V=\{v_1,v_2,\dots, v_n\}$ are the vertices, then the edges are $E=\{\{v_1,v_2\},\{v_2,v_3\},\dots,\{v_{n-1}, v_n\}\}$. This graph is called *the path graph*, $P_n$.
````

````{prf:definition} The Complete, Empty, & Path Graphs
Let $G=(V,E)$ such that $V=V=\{v_1,v_2,\dots, v_n\}$.

If $G$ is simple such that every pair of distinct vertices $v_i,v_j\in V$ has exactly one edge between them, $G$ is called *the complete graph*. We denote this graph $K_n$. 

If $G$ has no edges ($E$ is empty), $G$ is called *the empty graph*. We denote this graph $K_n^C$.

If $E$ has only edges between successive vertices ($E=\{\{v_1,v_2\},\{v_2,v_3\},\dots,\{v_{n-1}, v_n\}\}$), then $G$ is called *the path graph*. We denote this graph $P_n$.
````


### Subgraph Definitions

````{prf:defintion} Subgraphs
In short, a *subgraph* of a graph $G=(V,E)$ is obtained by removing vertices and/or edges (never adding either).

Formally, for graphs $G_1=(V_1,E_1)$ and $G_2,(V_2,E_2)$, we say $G_1$ is a subgraph of $G_2$ if 
1. $V_1\subseteq V_2$
2. Every edges appears no more often in $G_1$ as it does in $G_2$

If $G_1$ is a subgraph of $G_2$, we write $G_1\subseteq G_2$.

If $G_1$ is not $G_2$ itself, we say $G_1$ is a *proper* subgraph.
````

````{prf:definition} Induced Subgraphs
Let $G=(V,E)$ and $W\subseteq V$. The graph $G(W)=(W,E(W))$ where $E(W)=\{\{u,v\}|u,v\in W\}$ is an *induced* subgraph.
````

````{prf:definition} Cliques & Independent Sets
A *clique* is an induced subgraph that is a complete graph. We call the maximum size of a clique in $G$ the *clique number of G* and it is denoted $\omega(G)$.

An *independent set* is an induced subgraph that is an empty graph. We call the maximum size of an independent set in $G$ the *independence number of G* and it is denoted $\alpha(G)$.
````

````{prf:theorem} 
If $G_1=(V_1,E_1)\subseteq G_2=(V_2,E_2)$ with $W\subseteq V_1$, then $G_1(W)\subseteq G_2(W)$.
````
````{prf:proof} 
By definition, $G_1(W)$ and $G_2(W)$ have the same set of vertices, $W$. Since $G_1\subseteq G_2$, any edge appears no more often in $G_1$ than in $G_2$. Since this includes the edges of $G_1(W)$ and $G_2(W)$, we have $G_1(W)\subseteq G_2(W)$.
````

### Complement
````{prf:definition} Complement
Let $G=(V,E)$ be a simple graph. The *complement* of $G$ is the graph $G^C=(V,E^C)$ where $E^C=\{\{u,v\}|u\neq v \text{ and } \{u,v\}\notin E\}$.
````

### Coloring
Recall the committee problem from the first week of classes: {ref}`committeeexample`. What we wanted was to color the complete graph such that no edge had two of the same colored vertex. This is what we will define as *vertex coloring*.

````{prf:definition} $k$-Vertex Coloring
Let $G=(V,E)$ and $c:V\to \{1,2,\dots, k\}$ be function that assigns vertices colors. If $c(u)\neq c(v)$ for all $\{u,v\}\in E$, then $c$ is a $k$-vertex coloring of $G$.

Note: $k$-vertex coloring is so well-studied that if we say "coloring" or "$k$-coloring" we mean $k$-vertex coloring.
````

````{prf:definition} $k$-Colorability & Chromatic Number
A graph $G$ is *k-colorable* if there exists a $k$-coloring of $G$. The *chromatic number of G* is the minimum $k$ such that $G$ is $k$-colorable. We denote the chromatic number of $G$ as $\chi(G)$.
````
