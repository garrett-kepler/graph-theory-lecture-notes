````{prf:theorem} Menger's Theorem
Let $u$ and $v$ be distinct vertices in $G$ with \underline{no edge} between them. Then, the minimum number of vertices in a $uv$-separating set is exactly the maximum number of internally disjoint $uv$-paths (i.e. $\psi_G(u,v)=\kappa_G(u,v)$).
````

````{prf:definition}
Let $G$ be a graph with vertices $u$ and $v$ but not the edge $\{u,v\}$. Then,
1. $S\subseteq V$ is a *uv-separating set* if there is no $uv$-path in $G-S$. The minimum size of these sets will be denoted $\kappa_G(u,v)$.

2. Two $uv$-paths in $G$ are *internally disjoint uv-paths* if they only have the vertices $u$ and $v$ in common. The maximimum number of these for a graph $G$ will be denoted $\psi_G(u,v)$.
````
